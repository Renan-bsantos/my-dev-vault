# 🚀 RSCodes - Portfolio Website

Site portfólio profissional desenvolvido para RSCodes, apresentando serviços de desenvolvimento front-end, projetos e informações de contato.

## 🎨 Logo e Identidade Visual

### Arquivos de Logo
- **`logo.svg`** - Logo completo em alta resolução (200x200px)
- **`favicon.svg`** - Favicon para navegadores (64x64px)

### Design do Logo
O logo RSCodes foi criado com:
- **Letra "R"** estilizada representando Renan
- **Chaves de código** `{ }` representando programação
- **Gradiente moderno** (roxo #6366f1 → rosa #ec4899)
- **Design minimalista** e profissional

## 📁 Estrutura do Projeto

```
site/
├── index.html          # Página principal
├── style.css           # Estilos e animações
├── script.js           # Funcionalidades JavaScript
├── logo.svg            # Logo principal

```
